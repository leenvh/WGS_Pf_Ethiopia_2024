Overview

This document extracts Plasmodium falciparum drug-resistance regions from whole-genome BAM files, runs PathWeaver/SeekDeep variant calling on those regions, and summarizes amino-acid changes by sample and country.

The workflow has three main code chunks:

  1. The first R chunk creates the BED file used by PathWeaver. It reads the resistance amplicon table, keeps only rows marked as Resistance, removes genes that are not included in this run (exo, pib7, and pph), and selects chromosome, start, and end coordinates. It then builds the target name in the format expected by SeekDeep, for example Pf3D7_01_v3-194742-194973, assigns strand information for each gene, calculates the amplicon length, and writes the final BED file to data/bed/drug_resistance_mad4.bed.

  2. The Bash chunk runs the Nextflow PathWeaver extraction pipeline. It activates the nf-core conda environment, moves to the directory containing the BAM files, and launches pathweaver_extract_regions.nf. The command uses the BED file from the first chunk, the Pf3D7 reference genome, Apptainer containers, and -resume so completed tasks are reused. The --do_variant_calling option tells the pipeline to run SeekDeep variant calling after extracting and clustering the target regions.

  3. The final R chunk reads the SeekDeep amino-acid change summary and calculates country-level mutation prevalence. It first loads metadata containing sample country and fws, then cleans sample names in both the metadata and SeekDeep output so they can be joined. It keeps amino-acid calls with nonzero support (AA_cnt != 0), creates a per-sample mutation table, and then counts how many unique samples in each country carry each non-reference amino-acid change.

The object called allelic_freq is therefore a sample-level mutation prevalence table, not a read-weighted allele-frequency table. For each country, gene, and amino-acid position, the script calculates:

\[ ext{mutation prevalence} = \frac{\text{number of samples carrying the mutant amino acid}}{\text{number of samples with a call at that amino-acid position}} \]

Mixed infections or heterozygous-like calls are treated as carriers if the mutant amino acid has nonzero read support. For example, if a sample has both the reference amino acid and a mutant amino acid at the same position, the sample appears in the per-sample table with both calls and contributes one count to the mutant prevalence numerator. The sample is not weighted by AA_freq; a mutant present at 40% within a sample and a mutant present at 90% within a sample both count as one mutant-carrying sample in the prevalence calculation.

The following chunk creates an iTOL DATASET_COLORSTRIP annotation. Each tree tip is matched using the value in the Sample column, and the strip color represents the combined PX1 genotype at amino-acid positions 1222, 1701, and 1705. The tip labels in the Newick tree must exactly match these sample IDs. Haplotypes containing NA indicate that at least one target position did not have a genotype call; they are retained as separate categories and are not interpreted as wildtype.

## PX1 genotype annotation for iTOL

The following chunk creates an iTOL `DATASET_COLORSTRIP` annotation. Each tree tip is matched using the value in the `Sample` column, and the strip color represents the combined PX1 genotype at amino-acid positions 1222, 1701, and 1705. The tip labels in the Newick tree must exactly match these sample IDs. Haplotypes containing `NA` indicate that at least one target position did not have a genotype call; they are retained as separate categories and are not interpreted as wildtype.

```{r,eval=FALSE}
px1_itol <- readr::read_tsv(
  "output/px1_genotype_result/px1_genotype_result.tsv",
  show_col_types = FALSE
) %>%
  distinct(Sample, haplotype)

stopifnot(!anyDuplicated(px1_itol$Sample))

haplotypes <- sort(unique(px1_itol$haplotype))
haplotype_colors <- setNames(
  grDevices::hcl.colors(length(haplotypes), palette = "Dark 3"),
  haplotypes
)
haplotype_colors["WT/WT/WT"] <- "#BDBDBD"

itol_lines <- c(
  "DATASET_COLORSTRIP",
  "SEPARATOR TAB",
  "DATASET_LABEL\tPX1 genotype",
  "COLOR\t#000000",
  "STRIP_WIDTH\t50",
  "MARGIN\t5",
  "BORDER_WIDTH\t0",
  "SHOW_INTERNAL\t0",
  "LEGEND_TITLE\tPX1 genotype (1222/1701/1705)",
  paste("LEGEND_SHAPES", paste(rep(1, length(haplotypes)), collapse = "\t"), sep = "\t"),
  paste("LEGEND_COLORS", paste(haplotype_colors[haplotypes], collapse = "\t"), sep = "\t"),
  paste("LEGEND_LABELS", paste(haplotypes, collapse = "\t"), sep = "\t"),
  "DATA",
  paste(
    px1_itol$Sample,
    haplotype_colors[px1_itol$haplotype],
    px1_itol$haplotype,
    sep = "\t"
  )
)

itol_output <- "output/px1_genotype_result/px1_genotype_itol_colorstrip.txt"
writeLines(itol_lines, itol_output)
```
