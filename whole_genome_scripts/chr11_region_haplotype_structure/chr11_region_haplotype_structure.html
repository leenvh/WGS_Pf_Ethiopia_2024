HRP3-deleted monoclonal chromosome 11 haplotype structure

This chunk builds the first chromosome 11 haplotype rainbow plot for samples that are both monoclonal and HRP3-deleted. Monoclonal infections are selected using an FWS threshold of fws >= 0.95, HRP3-deleted samples are selected from deletion calls containing /hrp3-, and chromosome 11 subregions are restricted to positions at or after start >= 1954279. Samples are clustered from haplotype presence/absence profiles using Ward’s hierarchical clustering (ward.D2), then ordered by HRP deletion category and cluster order before plotting. The resulting plot shows haplotype structure across the selected chromosome 11 duplicated-region subwindows and is saved as duplicate_region_chr11.pdf.

add_haplotype_rainbow_axis_theming <-function(rainbow_plot, prepped_allele_data, target_col = "p_name", sample_col = "s_Sample"){
  return(rainbow_plot + 
           scale_x_continuous(
             labels = levels(prepped_allele_data[[target_col]]),
             breaks = 1:n_distinct(levels(prepped_allele_data[[target_col]])),
             expand = c(0,0)
           ) +
           scale_y_continuous(
             labels = levels(prepped_allele_data[[sample_col]]), 
             breaks = 1:n_distinct(levels(prepped_allele_data[[sample_col]])), 
             expand = c(0,0)
           ) + 
           theme(axis.text.y = element_text(family = "mono"), 
                 axis.text.x = element_text(family = "mono", angle = -90, hjust = 0)))
}

Two-unique-haplotype diverse-locus annotated plot

This chunk analyzes the two-unique-haplotype chromosome 11 cluster set and narrows the plot to loci with strong evidence of within-sample haplotype diversity. It first filters to chromosome 11 subregions and samples from the two-unique-haplotype cluster table, removes loci where all samples have a single averaged fraction, then calculates the proportion of samples with at least two alleles at each locus. Only loci where at least 50 percent of samples are multi-allelic (prop_multi >= 0.5) are retained, and loci must also pass the near-complete sample coverage filter (sampleCount >= 0.99 * max(sampleCount)). The selected samples are clustered by haplotype presence/absence using Ward’s method and plotted with annotations for site, HRP deletion status, and cluster.
