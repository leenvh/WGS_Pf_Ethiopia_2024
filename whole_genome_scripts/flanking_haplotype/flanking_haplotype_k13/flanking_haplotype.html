Build the sample sets and slice the genome-wide binary matrix

Rather than starting from scratch, the genome-wide binary matrix is subset directly. One major factor that affects a flanking-haplotype picture is sample clonality, so the sample lists are built so that the all-sample result can later be compared with a monoclonal-only result (previously all samples were used).

This chunk:

  • reads the genome-wide binary matrix (*.mat.bin) and drops the chr/ref columns, leaving pos plus one column per sample;
  • reads the per-site \(F_{WS}\) table and defines monoclonal samples as \(F_{WS} \ge 0.94\) (a slightly relaxed threshold because of small differences between the locally computed and the published \(F_{WS}\) values);
  • reads the k13 genotype table and keeps only samples carrying the 622I variant (genotype containing a 1);
  • builds two sample sets - Gondar + Eritrean 622I carriers, and Gambella + Uganda + South-East Asia samples for the 675V comparison;
  • slices the matrix to a 50 kb window around 622I (1,705,133-1,755,133; target position 1,725,133) and a 40 kb window around 675V (1,704,974-1,744,974; target position 1,724,974).

make_flanking_heatmap() - draw the SNP heatmap around a target variant

Several parameters change the appearance of a flanking-haplotype plot: the size of the window, which samples are included, and the distance metric used for clustering (Euclidean here, with Ward.D2 linkage). Widening the window increases the chance of picking up unrelated variants, which can change the clustering, so the window and the metric are passed in explicitly and reported in the plot title.

The function:

  • transposes the position-by-sample matrix into samples-by-position, replaces missing calls with 0 and recodes heterozygous 0.5 calls as 1;
  • drops positions that are invariant across the retained samples;
  • recodes the target column to 3 (target reference) / 4 (target alternate) so that it gets its own colours in the legend;
  • adds a left row annotation for the collection site and a top column annotation marking the target position in red;
  • clusters rows with hclust(dist(..., "euclidean"), method = "ward.D2"), keeping the columns in genomic order, and prints a check that the heatmap rows and the metadata rows are still aligned.

It is then applied to the 622I set (Gondar vs Eritrea) and to the 675V set (Gambella vs Uganda vs South-East Asia), writing each heatmap to a PDF.

Code
make_flanking_heatmap <- function(
  bin_file,
  target,
  title,
  metadata,
  range
) {
  ## -------------------------
  ## Read & prepare matrix
  ## -------------------------
  mat <- bin_file

  mat[is.na(mat)] <- 0

  df <- as.matrix(mat)
  rownames(df) <- mat$pos
  df <- df[, -1]
  df <- t(df)

  full_data <- data.frame(sample = rownames(df), df, check.names = FALSE)
  full_data[full_data == 0.5] <- 1
  full_data[is.na(full_data)] <- 0
  full_data <- full_data[, colSums(full_data != 0) > 0]

  ## -------------------------
  ## Encode target locus
  ## -------------------------
  full_data[[as.character(target)]] <- ifelse(
    full_data[[as.character(target)]] == 1,
    4,
    ifelse(
      full_data[[as.character(target)]] == 0,
      3,
      full_data[[as.character(target)]]
    )
  )

  mat_final <- as.matrix(full_data[, -1])
  rownames(mat_final) <- full_data$sample

  ## -------------------------
  ## Row annotation (metadata)
  ## -------------------------
  metadata_2 <- metadata %>%
    filter(sample %in% rownames(mat_final)) %>%
    column_to_rownames("sample")
  metadata_2 <- metadata_2[rownames(mat_final), , drop = FALSE]
  site_colors <- c(
    "Ethiopia" = "#1b9e77", # teal-green
    "Uganda" = "#7570b3", # soft purple
    "south_east_asia" = "#66a61e", # olive green
    "Gondar" = "#e6ab02", # mustard yellow
    "Gambella" = "#d95f02", # orange-red (less harsh than pure red)
    "Eritria" = "#e7298a", # pink-magenta
    "unknown" = "#666666" # neutral gray (better than black)
  )

  ha_row <- rowAnnotation(
    site = metadata_2$site,
    col = list(site = site_colors)
  )

  ## -------------------------
  ## Column annotation (target)
  ## -------------------------
  ha_col <- columnAnnotation(
    Target = ifelse(colnames(mat_final) == target, "Target", ""),
    col = list(Target = c("Target" = "red")),
    show_annotation_name = FALSE,
    show_legend = FALSE
  )

  ## -------------------------
  ## Colors
  ## -------------------------
  col_fun <- colorRamp2(
    breaks = c(0, 1, 3, 4),
    colors = c(
      "#F2F2F2", # REF
      "#2C7FB8", # ALT
      "#f6ff00", # Target REF
      "#ff230a96" # Target ALT
    )
  )

  ## -------------------------
  ## Clustering
  ## -------------------------
  #rowcluster <- hclust(dist(mat_final), method = "ward.D2")
  rowcluster <- hclust(
    dist(mat_final, method = "euclidean"),
    method = "ward.D2"
  )
  # After reordering, verify alignment
  cat("Checking alignment:\n")
  cat("First 5 samples in heatmap:", head(rownames(mat_final)), "\n")
  cat("First 5 samples in metadata:", head(rownames(metadata_2)), "\n")
  cat(
    "Are they identical?",
    all(rownames(mat_final) == rownames(metadata_2)),
    "\n"
  )
  ## -------------------------
  ## Heatmap
  ## -------------------------
  Heatmap(
    mat_final,
    name = title,
    col = col_fun,
    cluster_rows = rowcluster,
    cluster_columns = FALSE,
    left_annotation = ha_row,
    top_annotation = ha_col,
    show_row_names = TRUE,
    show_column_names = FALSE,
    use_raster = FALSE,
    row_names_gp = grid::gpar(fontsize = 8),
    column_title = paste0(
      title,
      " ",
      "Target: ",
      target,
      " ",
      "range= ",
      range
    ),
    heatmap_legend_param = list(
      title = "Genotype",
      at = c(0, 1, 3, 4),
      labels = c("REF", "ALT", "Target (REF)", "Target (ALT)")
    )
  )
}

Create the tiled BED file flanking the 622I variant

That region is then cut into overlapping-free 200 bp windows, converted to 0-based BED coordinates, and windows shorter than 50 bp (the trailing remainder) are dropped. Each window becomes one PathWeaver “target”, so the final heatmaps have one column per 200 bp window.

Helper functions for the haplotype rainbow plots and clustering

Four reusable helpers are defined here:

  • resort_prepped_samples_by_clustering() - keeps only targets that were successfully assembled in at least target_sample_coverage_freq_cut_off of samples, optionally reduces each sample/target to its major allele, builds a sample x haplotype presence/absence matrix, clusters it (Ward.D2 on Euclidean distance) and returns the data with the sample column re-levelled in dendrogram order so related samples sit next to each other in the plot.
  • add_haplotype_rainbow_axis_theming() - restores the real target and sample labels on the numeric axes of the rainbow plot and rotates the x labels.
  • createColorListFromDf() - generates a named colour vector per metadata column, expanding an RColorBrewer palette when there are more categories than the palette provides.
  • matrix_to_tibble() - converts a square distance/similarity matrix into a long sample1/sample2/value tibble, optionally dropping the diagonal and the redundant lower triangle.
  • single_linkage_clusters() - builds a graph linking every pair below a distance threshold and returns the connected components, i.e. single-linkage clusters of highly related samples.
Code
resort_prepped_samples_by_clustering <- function(
  prepped_allele_data,
  sampleCol = s_Sample,
  targetCol = p_name,
  popUIDCol = h_popUID,
  relAbundCol = c_AveragedFrac,
  target_sample_coverage_freq_cut_off = 0.80,
  by_major_allele = FALSE
) {
  stopifnot(is.data.frame(prepped_allele_data))

  # total distinct samples (used for coverage frequency)
  n_samples_total <- dplyr::n_distinct(dplyr::pull(
    prepped_allele_data,
    {{ sampleCol }}
  ))

  # targets with sufficient sample coverage
  targets_keep <- prepped_allele_data %>%
    ungroup() |>
    group_by({{ targetCol }}) |>
    dplyr::summarise(
      sample_count = dplyr::n_distinct({{ sampleCol }})
    ) %>%
    dplyr::mutate(sample_freq = sample_count / n_samples_total) %>%
    dplyr::filter(sample_freq >= target_sample_coverage_freq_cut_off) %>%
    dplyr::pull({{ targetCol }}) |>
    unique()
  if (length(targets_keep) == 0) {
    stop("no targets above sample coverage cut off")
  }
  dat <- prepped_allele_data %>%
    filter({{ targetCol }} %in% targets_keep)

  # optionally keep only major allele per (sample, target)
  if (by_major_allele) {
    dat <- dat %>%
      dplyr::group_by({{ sampleCol }}, {{ targetCol }}) %>%
      dplyr::slice_max(
        order_by = {{ relAbundCol }},
        n = 1,
        with_ties = FALSE
      ) %>%
      dplyr::ungroup()
  }

  # build sample x popUID presence/absence matrix
  dat_sp <- dat %>%
    mutate(new_identifier = paste0({{ targetCol }}, "-", {{ popUIDCol }})) |>
    ungroup() |>
    dplyr::select({{ sampleCol }}, new_identifier) %>%
    unique() |>
    dplyr::mutate(marker = 1L) %>%
    tidyr::pivot_wider(
      names_from = new_identifier,
      values_from = marker,
      values_fill = 0L
    )

  # matrix for clustering
  dat_sp_mat <- as.matrix(dat_sp[, 2:ncol(dat_sp)])
  rownames(dat_sp_mat) <- dat_sp |>
    dplyr::pull({{ sampleCol }})
  dat_sp_mat_hc <- stats::hclust(stats::dist(dat_sp_mat), method = "ward.D2")
  sample_levels <- rownames(dat_sp_mat)[dat_sp_mat_hc$order]

  # add any samples that were filtered off to the end
  any_missing_samples <- prepped_allele_data %>%
    filter(!({{ sampleCol }} %in% sample_levels)) |>
    ungroup() |>
    dplyr::pull({{ sampleCol }})

  sample_levels <- c(
    as.character(sample_levels),
    as.character(any_missing_samples)
  )

  prepped_allele_data %>%
    dplyr::mutate(
      {{ sampleCol }} := factor({{ sampleCol }}, levels = sample_levels)
    )
}

createColorListFromDf <- function(df, palette = "Accent") {
  # Load required package
  library(RColorBrewer)

  color_lists <- list()

  for (col_name in colnames(df)) {
    # Get unique categories
    categories <- unique(as.character(df[[col_name]]))

    # Generate colors
    n_colors <- length(categories)

    if (n_colors <= 8) {
      colors <- brewer.pal(max(3, n_colors), palette)[1:n_colors]
    } else {
      colors <- colorRampPalette(brewer.pal(8, palette))(n_colors)
    }

    # Create mapping
    color_map <- setNames(colors, categories)

    # Map colors to rows
    color_lists[[col_name]] <- color_map[as.character(df[[col_name]])]
  }

  return(color_lists)
}


matrix_to_tibble <- function(
  mat,
  dist_col_name = "distance",
  upper_tri_only = FALSE,
  include_diagonal = FALSE
) {
  # Validate input
  if (!is.matrix(mat)) {
    mat <- as.matrix(mat)
  }
  if (is.null(rownames(mat)) || is.null(colnames(mat))) {
    stop("Matrix must have both row names and column names.")
  }

  # Convert to long format tibble
  result <- mat |>
    as.data.frame() |>
    rownames_to_column(var = "sample1") |>
    pivot_longer(
      cols = -sample1,
      names_to = "sample2",
      values_to = dist_col_name
    ) |>
    as_tibble()

  # Optionally remove diagonal (self-comparisons)
  if (!include_diagonal) {
    result <- result |> filter(sample1 != sample2)
  }

  # Optionally keep only upper triangle
  if (upper_tri_only) {
    # Keep pairs where sample1 appears before sample2 in the row name order
    sample_levels <- rownames(mat)
    result <- result |>
      filter(
        match(sample1, sample_levels) < match(sample2, sample_levels)
      )
  }

  return(result)
}


single_linkage_clusters <- function(
  df,
  distance_col,
  threshold,
  sample_col = sample,
  other_sample_col = other_sample
) {
  edges <- df %>%
    filter({{ distance_col }} <= threshold) %>%
    transmute(
      from = as.character({{ sample_col }}),
      to = as.character({{ other_sample_col }})
    )

  verts <- tibble(
    name = unique(c(
      as.character(df |> pull({{ sample_col }})),
      as.character(df |> pull({{ other_sample_col }}))
    ))
  )

  g <- graph_from_data_frame(edges, directed = FALSE, vertices = verts)

  comps <- components(g)$membership

  tibble(
    sample = names(comps),
    cluster = as.integer(comps)
  ) %>%
    arrange(cluster, sample)
}

Single-linkage clustering and a colour-consistent Jaccard heatmap

The same Jaccard matrix is reworked with tighter control over the colours. The matrix is flattened to a long tibble (upper triangle only), converted to a distance (1 - jaccard) and passed to single_linkage_clusters() with a threshold of 0.05 - so any two samples sharing at least 95% of their haplotypes are joined, and the connected components become clonal-lineage clusters.

create_consistent_colors() then fixes the palette per annotation (hard-coded country and genotype colours, Brewer ramps for site and cluster) and the same list is reused for the row annotation, the column annotation and the manually built legends. This guarantees that a given country/genotype is the same colour everywhere, which was not the case when the colours were regenerated separately. Legends are drawn manually with Legend()/packLegend() and the figure is saved as PNG and PDF.

# Function to create consistent color mapping
create_consistent_colors <- function(df) {
  color_list <- list()
  
  # Country colors
  if ("Country" %in% colnames(df)) {
    countries <- sort(unique(na.omit(df$Country)))
    country_palette <- c(
      "Ethiopia" = "#2E86AB", 
      
      "Eritrea" = "#F18F01",
      "Somalia" = "#4DAF4A"
    )
    # Only keep countries that exist in data
    color_list$Country <- country_palette[names(country_palette) %in% countries]
    # Add any missing countries with new colors
    missing_countries <- setdiff(countries, names(color_list$Country))
    if (length(missing_countries) > 0) {
      new_colors <- colorRampPalette(brewer.pal(8, "Set1"))(length(missing_countries))
      names(new_colors) <- missing_countries
      color_list$Country <- c(color_list$Country, new_colors)
    }
  }
  
  # Site colors
  if ("Site" %in% colnames(df)) {
    sites <- sort(unique(na.omit(df$Site)))
    site_colors <- colorRampPalette(brewer.pal(8, "Set2"))(length(sites))
    names(site_colors) <- sites
    color_list$Site <- site_colors
  }
  
  # Genotype colors
  if ("genotype" %in% colnames(df)) {
    genotypes <- sort(unique(na.omit(df$genotype)))
    # Define standard genotype colors
    genotype_palette <- c(
      "0/0" = "#E41A1C",
      "0/1" = "#377EB8",
      "1/1" = "#4DAF4A",
      "./." = "#984EA3",
      "0|0" = "#E41A1C",
      "0|1" = "#377EB8",
      "1|1" = "#4DAF4A"
    )
    # Only keep genotypes that exist
    color_list$genotype <- genotype_palette[names(genotype_palette) %in% genotypes]
    # Add any missing genotypes
    missing_genotypes <- setdiff(genotypes, names(color_list$genotype))
    if (length(missing_genotypes) > 0) {
      new_colors <- colorRampPalette(brewer.pal(8, "Set3"))(length(missing_genotypes))
      names(new_colors) <- missing_genotypes
      color_list$genotype <- c(color_list$genotype, new_colors)
    }
  }
  
  # Cluster colors
  if ("cluster" %in% colnames(df)) {
    clusters <- sort(unique(na.omit(df$cluster)))
    cluster_colors <- colorRampPalette(brewer.pal(8, "Dark2"))(length(clusters))
    names(cluster_colors) <- clusters
    color_list$cluster <- cluster_colors
  }
  
  return(color_list)
}

        labels_gp = gpar(fontsize = 12),
        grid_height = unit(6, "mm"),
        grid_width = unit(6, "mm")

Comparing haplotype sharing with genome-wide relatedness

Build a split heatmap: hmmIBD below the diagonal, Jaccard above it

This chunk asks whether samples that share k13 flanking haplotypes are also related genome-wide. The hmmIBD output (fract_sites_IBD per pair) is read and restricted to the pairs that also have a Jaccard value, using an order-independent pair_id built with pmin()/pmax(). Self-comparisons are added with a value of 1 so the diagonal is complete.

Two symmetric matrices are filled over the same sample set (monoclonal, \(F_{WS} > 0.95\)), and the samples are ordered by country, then site, then 622I genotype rather than by clustering, so the geographic blocks are directly comparable between the two halves. Genotype strings are cleaned first (leftover b'...' byte encoding, quotes, whitespace, | to /) because otherwise the annotation colours silently fail to match.

The heatmap is drawn with rect_gp = gpar(type = "none") and a custom layer_fun, which paints each cell manually: the lower triangle uses the IBD colour ramp (binned at 0.2 / 0.5 / 0.8), the upper triangle uses the Jaccard ramp, and the diagonal is black. All legends are packed manually and the figure is written to PDF and PNG.

### `make_flanking_heatmap()` - draw the SNP heatmap around a target variant

Several parameters change the appearance of a flanking-haplotype plot: the size
of the window, which samples are included, and the distance metric used for
clustering (Euclidean here, with Ward.D2 linkage). Widening the window increases
the chance of picking up unrelated variants, which can change the clustering, so
the window and the metric are passed in explicitly and reported in the plot
title.

The function:

* transposes the position-by-sample matrix into samples-by-position, replaces
  missing calls with `0` and recodes heterozygous `0.5` calls as `1`;
* drops positions that are invariant across the retained samples;
* recodes the **target** column to `3` (target reference) / `4` (target alternate)
  so that it gets its own colours in the legend;
* adds a left row annotation for the collection site and a top column annotation
  marking the target position in red;
* clusters rows with `hclust(dist(..., "euclidean"), method = "ward.D2")`,
  keeping the columns in genomic order, and prints a check that the heatmap rows
  and the metadata rows are still aligned.

It is then applied to the 622I set (Gondar vs Eritrea) and to the 675V set
(Gambella vs Uganda vs South-East Asia), writing each heatmap to a PDF.

```{r,eval=FALSE}

make_flanking_heatmap <- function(
  bin_file,
  target,
  title,
  metadata,
  range
) {
  ## -------------------------
  ## Read & prepare matrix
  ## -------------------------
  mat <- bin_file

  mat[is.na(mat)] <- 0

  df <- as.matrix(mat)
  rownames(df) <- mat$pos
  df <- df[, -1]
  df <- t(df)

  full_data <- data.frame(sample = rownames(df), df, check.names = FALSE)
  full_data[full_data == 0.5] <- 1
  full_data[is.na(full_data)] <- 0
  full_data <- full_data[, colSums(full_data != 0) > 0]

  ## -------------------------
  ## Encode target locus
  ## -------------------------
  full_data[[as.character(target)]] <- ifelse(
    full_data[[as.character(target)]] == 1,
    4,
    ifelse(
      full_data[[as.character(target)]] == 0,
      3,
      full_data[[as.character(target)]]
    )
  )

  mat_final <- as.matrix(full_data[, -1])
  rownames(mat_final) <- full_data$sample

  ## -------------------------
  ## Row annotation (metadata)
  ## -------------------------
  metadata_2 <- metadata %>%
    filter(sample %in% rownames(mat_final)) %>%
    column_to_rownames("sample")
  metadata_2 <- metadata_2[rownames(mat_final), , drop = FALSE]
  site_colors <- c(
    "Ethiopia" = "#1b9e77", # teal-green
    "Uganda" = "#7570b3", # soft purple
    "south_east_asia" = "#66a61e", # olive green
    "Gondar" = "#e6ab02", # mustard yellow
    "Gambella" = "#d95f02", # orange-red (less harsh than pure red)
    "Eritria" = "#e7298a", # pink-magenta
    "unknown" = "#666666" # neutral gray (better than black)
  )

  ha_row <- rowAnnotation(
    site = metadata_2$site,
    col = list(site = site_colors)
  )

  ## -------------------------
  ## Column annotation (target)
  ## -------------------------
  ha_col <- columnAnnotation(
    Target = ifelse(colnames(mat_final) == target, "Target", ""),
    col = list(Target = c("Target" = "red")),
    show_annotation_name = FALSE,
    show_legend = FALSE
  )

  ## -------------------------
  ## Colors
  ## -------------------------
  col_fun <- colorRamp2(
    breaks = c(0, 1, 3, 4),
    colors = c(
      "#F2F2F2", # REF
      "#2C7FB8", # ALT
      "#f6ff00", # Target REF
      "#ff230a96" # Target ALT
    )
  )

  ## -------------------------
  ## Clustering
  ## -------------------------
  #rowcluster <- hclust(dist(mat_final), method = "ward.D2")
  rowcluster <- hclust(
    dist(mat_final, method = "euclidean"),
    method = "ward.D2"
  )
  # After reordering, verify alignment
  cat("Checking alignment:\n")
  cat("First 5 samples in heatmap:", head(rownames(mat_final)), "\n")
  cat("First 5 samples in metadata:", head(rownames(metadata_2)), "\n")
  cat(
    "Are they identical?",
    all(rownames(mat_final) == rownames(metadata_2)),
    "\n"
  )
  ## -------------------------
  ## Heatmap
  ## -------------------------
  Heatmap(
    mat_final,
    name = title,
    col = col_fun,
    cluster_rows = rowcluster,
    cluster_columns = FALSE,
    left_annotation = ha_row,
    top_annotation = ha_col,
    show_row_names = TRUE,
    show_column_names = FALSE,
    use_raster = FALSE,
    row_names_gp = grid::gpar(fontsize = 8),
    column_title = paste0(
      title,
      " ",
      "Target: ",
      target,
      " ",
      "range= ",
      range
    ),
    heatmap_legend_param = list(
      title = "Genotype",
      at = c(0, 1, 3, 4),
      labels = c("REF", "ALT", "Target (REF)", "Target (ALT)")
    )
  )
}
```

### Helper functions for the haplotype rainbow plots and clustering

Four reusable helpers are defined here:

* **`resort_prepped_samples_by_clustering()`** - keeps only targets that were
  successfully assembled in at least `target_sample_coverage_freq_cut_off` of
  samples, optionally reduces each sample/target to its major allele, builds a
  sample x haplotype presence/absence matrix, clusters it (Ward.D2 on Euclidean
  distance) and returns the data with the sample column re-levelled in
  dendrogram order so related samples sit next to each other in the plot.
* **`add_haplotype_rainbow_axis_theming()`** - restores the real target and
  sample labels on the numeric axes of the rainbow plot and rotates the x labels.
* **`createColorListFromDf()`** - generates a named colour vector per metadata
  column, expanding an RColorBrewer palette when there are more categories than
  the palette provides.
* **`matrix_to_tibble()`** - converts a square distance/similarity matrix into a
  long `sample1`/`sample2`/`value` tibble, optionally dropping the diagonal and
  the redundant lower triangle.
* **`single_linkage_clusters()`** - builds a graph linking every pair below a
  distance threshold and returns the connected components, i.e. single-linkage
  clusters of highly related samples.

```{r}
resort_prepped_samples_by_clustering <- function(
  prepped_allele_data,
  sampleCol = s_Sample,
  targetCol = p_name,
  popUIDCol = h_popUID,
  relAbundCol = c_AveragedFrac,
  target_sample_coverage_freq_cut_off = 0.80,
  by_major_allele = FALSE
) {
  stopifnot(is.data.frame(prepped_allele_data))

  # total distinct samples (used for coverage frequency)
  n_samples_total <- dplyr::n_distinct(dplyr::pull(
    prepped_allele_data,
    {{ sampleCol }}
  ))

  # targets with sufficient sample coverage
  targets_keep <- prepped_allele_data %>%
    ungroup() |>
    group_by({{ targetCol }}) |>
    dplyr::summarise(
      sample_count = dplyr::n_distinct({{ sampleCol }})
    ) %>%
    dplyr::mutate(sample_freq = sample_count / n_samples_total) %>%
    dplyr::filter(sample_freq >= target_sample_coverage_freq_cut_off) %>%
    dplyr::pull({{ targetCol }}) |>
    unique()
  if (length(targets_keep) == 0) {
    stop("no targets above sample coverage cut off")
  }
  dat <- prepped_allele_data %>%
    filter({{ targetCol }} %in% targets_keep)

  # optionally keep only major allele per (sample, target)
  if (by_major_allele) {
    dat <- dat %>%
      dplyr::group_by({{ sampleCol }}, {{ targetCol }}) %>%
      dplyr::slice_max(
        order_by = {{ relAbundCol }},
        n = 1,
        with_ties = FALSE
      ) %>%
      dplyr::ungroup()
  }

  # build sample x popUID presence/absence matrix
  dat_sp <- dat %>%
    mutate(new_identifier = paste0({{ targetCol }}, "-", {{ popUIDCol }})) |>
    ungroup() |>
    dplyr::select({{ sampleCol }}, new_identifier) %>%
    unique() |>
    dplyr::mutate(marker = 1L) %>%
    tidyr::pivot_wider(
      names_from = new_identifier,
      values_from = marker,
      values_fill = 0L
    )

  # matrix for clustering
  dat_sp_mat <- as.matrix(dat_sp[, 2:ncol(dat_sp)])
  rownames(dat_sp_mat) <- dat_sp |>
    dplyr::pull({{ sampleCol }})
  dat_sp_mat_hc <- stats::hclust(stats::dist(dat_sp_mat), method = "ward.D2")
  sample_levels <- rownames(dat_sp_mat)[dat_sp_mat_hc$order]

  # add any samples that were filtered off to the end
  any_missing_samples <- prepped_allele_data %>%
    filter(!({{ sampleCol }} %in% sample_levels)) |>
    ungroup() |>
    dplyr::pull({{ sampleCol }})

  sample_levels <- c(
    as.character(sample_levels),
    as.character(any_missing_samples)
  )

  prepped_allele_data %>%
    dplyr::mutate(
      {{ sampleCol }} := factor({{ sampleCol }}, levels = sample_levels)
    )
}


add_haplotype_rainbow_axis_theming <- function(
  rainbow_plot,
  prepped_allele_data,
  sampleCol = s_Sample,
  targetCol = p_name
) {
  target_levels <- levels(prepped_allele_data |> pull({{ targetCol }}))
  sample_levels <- levels(prepped_allele_data |> pull({{ sampleCol }}))
  return(

      ) +
      scale_y_continuous(

        breaks = 1:n_distinct(sample_levels),
        expand = c(0, 0)
      ) +
      theme(
        axis.text.y = element_text(family = "mono"),
        axis.text.x = element_text(family = "mono", angle = -90, hjust = 0)
      )
  )
}

createColorListFromDf <- function(df, palette = "Accent") {
  # Load required package
  library(RColorBrewer)

  color_lists <- list()

  for (col_name in colnames(df)) {
    # Get unique categories
    categories <- unique(as.character(df[[col_name]]))

    # Generate colors
    n_colors <- length(categories)

    if (n_colors <= 8) {
      colors <- brewer.pal(max(3, n_colors), palette)[1:n_colors]
    } else {
      colors <- colorRampPalette(brewer.pal(8, palette))(n_colors)
    }

    # Create mapping
    color_map <- setNames(colors, categories)

    # Map colors to rows
    color_lists[[col_name]] <- color_map[as.character(df[[col_name]])]
  }

  return(color_lists)
}


matrix_to_tibble <- function(
  mat,
  dist_col_name = "distance",
  upper_tri_only = FALSE,
  include_diagonal = FALSE
) {
  # Validate input
  if (!is.matrix(mat)) {
    mat <- as.matrix(mat)
  }
  if (is.null(rownames(mat)) || is.null(colnames(mat))) {
    stop("Matrix must have both row names and column names.")
  }

  # Convert to long format tibble
  result <- mat |>
    as.data.frame() |>
    rownames_to_column(var = "sample1") |>
    pivot_longer(
      cols = -sample1,
      names_to = "sample2",
      values_to = dist_col_name
    ) |>
    as_tibble()

  # Optionally remove diagonal (self-comparisons)
  if (!include_diagonal) {
    result <- result |> filter(sample1 != sample2)
  }

  # Optionally keep only upper triangle
  if (upper_tri_only) {
    # Keep pairs where sample1 appears before sample2 in the row name order
    sample_levels <- rownames(mat)
    result <- result |>
      filter(
        match(sample1, sample_levels) < match(sample2, sample_levels)
      )
  }

  return(result)
}


single_linkage_clusters <- function(
  df,
  distance_col,
  threshold,
  sample_col = sample,
  other_sample_col = other_sample
) {
  edges <- df %>%
    filter({{ distance_col }} <= threshold) %>%
    transmute(
      from = as.character({{ sample_col }}),
      to = as.character({{ other_sample_col }})
    )

  verts <- tibble(
    name = unique(c(
      as.character(df |> pull({{ sample_col }})),
      as.character(df |> pull({{ other_sample_col }}))
    ))
  )

  g <- graph_from_data_frame(edges, directed = FALSE, vertices = verts)

  comps <- components(g)$membership

  tibble(
    sample = names(comps),
    cluster = as.integer(comps)
  ) %>%
    arrange(cluster, sample)
}
```

### Single-linkage clustering and a colour-consistent Jaccard heatmap

The same Jaccard matrix is reworked with tighter control over the colours. The
matrix is flattened to a long tibble (upper triangle only), converted to a
distance (`1 - jaccard`) and passed to `single_linkage_clusters()` with a
threshold of 0.05 - so any two samples sharing at least 95% of their haplotypes
are joined, and the connected components become clonal-lineage clusters.

`create_consistent_colors()` then fixes the palette per annotation (hard-coded
country and genotype colours, Brewer ramps for site and cluster) and the *same*
list is reused for the row annotation, the column annotation and the manually
built legends. This guarantees that a given country/genotype is the same colour
everywhere, which was not the case when the colours were regenerated separately.
Legends are drawn manually with `Legend()`/`packLegend()` and the figure is saved

### Expected heterozygosity, coverage and haplotype counts per target

`allDiversityMeasures.tsv.gz` reports one row per 200 bp target. Three stacked
panels are built with **patchwork**:

* **He** - expected heterozygosity, i.e. how diverse each window is. Windows
  around a recently selected variant are expected to show reduced diversity.
* **Sample count** - how many samples assembled that window, which shows whether a
  low He is real or simply the result of poor coverage.
* **Total haplotypes** - the number of distinct sequence haplotypes per window.

The x-axis labels are removed from the top two panels because all three share the
same target ordering. The combined figure is saved at 8 x 10 inches, 300 dpi.
